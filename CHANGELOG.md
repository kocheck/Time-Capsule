# Changelog

All notable changes to Time Capsule will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial implementation of Time Capsule
- AI-powered task suggestions (Apple Intelligence + Ollama)
- Context-aware task ranking
- Focus mode for repeatedly skipped tasks
- Daily progress tracking and streaks
- Tag-based organization
- Priority levels (High, Normal, Low)
- Menu bar integration
- Onboarding flow
- Settings management
- Notification support
- Badge count display
- Rule-based fallback when AI unavailable

### Features
- SwiftUI-based native macOS interface
- SwiftData persistence layer
- MVVM architecture with @Observable
- Actor-based context engine
- Modular AI service architecture
- Comprehensive unit tests
- GitHub Actions CI/CD
- SwiftLint integration

## [1.0.0] - 2026-01-16

### Added
- Initial release of Time Capsule
- Core task management functionality
- AI-powered suggestions
- Progress tracking
- Menu bar app interface
