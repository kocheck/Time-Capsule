## Prerequisites

### System Requirements

- **macOS**: 14.0 (Sonoma) or later
- **Xcode**: 16.0 or later
- **Swift**: 5.10+ (bundled with Xcode)

### Development Tools

Install required tools using the setup script:

```bash
make setup
```

This installs:
- **SwiftLint**: Code linting and security checks
- **xcbeautify**: Better build output formatting

Or install manually:

```bash
brew install swiftlint xcbeautify
```

## Creating the Xcode Project

The repository doesn't include the `.xcodeproj` file, so you'll need to create it. Follow these steps carefully:

### Step 1: Create New Project

1. Open Xcode
2. Select **File → New → Project** (⇧⌘N)
3. Choose **macOS → App**
4. Click **Next**

### Step 2: Configure Project Details

Enter the following settings:

| Field | Value |
|-------|-------|
| **Product Name** | `TimeCapsule` |
| **Team** | Select your development team |
| **Organization Identifier** | `com.yourdomain` (or your preferred identifier) |
| **Bundle Identifier** | Will auto-generate as `com.yourdomain.TimeCapsule` |
| **Interface** | SwiftUI |
| **Language** | Swift |
| **Storage** | None (we'll use SwiftData manually) |

**Important**: Uncheck all checkboxes:
- ☐ Use Core Data
- ☐ Include Tests
- ☐ Include UI Tests
- ☐ Create Git repository

### Step 3: Save Project Location

1. Click **Next**
2. **Navigate to your cloned repository root** (`/path/to/Time-Capsule/`)
3. **Name the project**: `TimeCapsule`
4. Click **Create**

**Critical**: The project file should be saved as `TimeCapsule.xcodeproj` directly in the repository root, at the same level as the `Makefile`.

### Step 4: Delete Default Files

Xcode will create some default files. Delete these (Move to Trash):

- Delete: `TimeCapsuleApp.swift` (generated by Xcode)
- Delete: `ContentView.swift`
- Delete: `Assets.xcassets` folder (if created)
- Delete: `Preview Content` folder (if created)

## Configuring Project Settings

### Step 5: General Settings

1. Select the `TimeCapsule` project in the navigator
2. Select the `TimeCapsule` target
3. Go to the **General** tab

#### Identity

| Setting | Value |
|---------|-------|
| **Display Name** | Time Capsule |
| **Bundle Identifier** | `com.yourdomain.TimeCapsule` |
| **Version** | 1.0 |
| **Build** | 1 |

#### Deployment Info

| Setting | Value |
|---------|-------|
| **Minimum Deployments** | macOS 14.0 |
| **Mac Catalyst** | Unchecked |

#### Frameworks and Libraries

No external frameworks needed. All dependencies are system frameworks (SwiftUI, SwiftData, Foundation).

### Step 6: Signing & Capabilities

1. Go to **Signing & Capabilities** tab
2. **Signing**:
   - ☑ Automatically manage signing
   - Select your **Team**

3. **Add Capabilities** (click + Capability):

   Add the following capabilities:

   - **App Sandbox** ✓
     - ☑ Outgoing Connections (Client)
     - ☑ User Selected File (Read/Write)

   - **Hardened Runtime** ✓
     - This should be enabled by default

4. **Optional**: Add **iCloud** capability if you want to sync data across devices:
   - Add **iCloud** capability
   - ☑ CloudKit
   - ☑ Key-value storage
   - Add a container: `iCloud.com.yourdomain.TimeCapsule`

### Step 7: Build Settings

1. Select the `TimeCapsule` target
2. Go to **Build Settings** tab
3. Search for and configure these settings:

#### Swift Compiler

| Setting | Value |
|---------|-------|
| **Swift Language Version** | Swift 5 |
| **Enable Strict Concurrency** | Complete |
| **Upcoming Features** | Enable all |

#### Deployment

| Setting | Value |
|---------|-------|
| **macOS Deployment Target** | 14.0 |
| **Skip Install** | No |

#### Packaging

| Setting | Value |
|---------|-------|
| **Product Name** | TimeCapsule |
| **Product Bundle Identifier** | `com.yourdomain.TimeCapsule` |

#### Apple Clang - Code Generation

| Setting | Value |
|---------|-------|
| **Optimization Level (Debug)** | None [-O0] |
| **Optimization Level (Release)** | Optimize for Speed [-O] |

## Adding Source Files

### Step 8: Add Source File Groups

Now add all the source code to the project. It's important to maintain the folder structure.

#### Method 1: Add Folders (Recommended)

1. Right-click on the `TimeCapsule` group in the Project Navigator
2. Select **Add Files to "TimeCapsule"...**
3. Navigate to the repository's `TimeCapsule` folder
4. Select ALL folders inside:
   - `App`
   - `Models`
   - `Views`
   - `ViewModels`
   - `Services`
   - `Utilities`
   - `Resources`
   - `Preview Content`

5. **Important**: Check these options:
   - ☑ **Copy items if needed** (UNCHECK this - we want references)
   - ☑ **Create groups** (not folder references)
   - ☑ **Add to targets**: TimeCapsule

6. Click **Add**

#### Method 2: Drag and Drop

Alternatively, you can drag the folders from Finder:

1. Open Finder and navigate to the `TimeCapsule` source folder
2. Select all subdirectories
3. Drag them into the Xcode `TimeCapsule` group
4. In the dialog:
   - ☐ Uncheck "Copy items if needed"
   - ☑ Check "Create groups"
   - ☑ Check "Add to targets: TimeCapsule"

1. Select `Resources/Info.plist`
2. Add these keys (if not present):

## Configuring Build Settings

### Step 15: Configure Build Schemes

1. Click on the scheme selector (top-left, next to Stop button)
2. Select **Edit Scheme...** (⌘<)

#### Run Scheme Configuration:

1. Select **Run** in the sidebar
2. **Info** tab:
   - Build Configuration: **Debug**
   - Executable: **TimeCapsule.app**

3. **Options** tab:
   - ☐ Uncheck "Debug executable"
   - Or keep it checked for debugging

#### Test Scheme Configuration:

1. Select **Test** in the sidebar
2. Ensure all test targets are checked:
   - ☑ TimeCapsuleTests
3. **Info** tab:
   - Build Configuration: **Debug**
4. **Options** tab:
   - ☑ Check "Code Coverage" (recommended)

5. Click **Close**

### Step 16: Add Run Script Phase for SwiftLint

Add SwiftLint to run automatically on build:

1. Select `TimeCapsule` target
2. Go to **Build Phases** tab
3. Click **+** → **New Run Script Phase**
4. Drag it above "Compile Sources"
5. Name it: "SwiftLint"
6. Add this script:

```bash
if [[ "$(command -v swiftlint)" == "" ]]; then
    echo "warning: SwiftLint not installed, download from https://github.com/realm/SwiftLint"
    exit 0
fi

# Run SwiftLint
swiftlint lint --config "${SRCROOT}/.swiftlint.yml"
```

7. **Input Files**: (optional, for caching)
   ```
   $(SRCROOT)/.swiftlint.yml
   ```

8. **Output Files**: (optional, for caching)
   ```
   $(DERIVED_FILE_DIR)/swiftlint.txt
   ```

## Building and Running

### Step 17: Initial Build

1. Select **Product → Clean Build Folder** (⇧⌘K)
2. Select **Product → Build** (⌘B)

The build should succeed. If you see SwiftLint warnings, that's normal for first build.

### Step 18: Run the Application

1. Select **Product → Run** (⌘R)
2. The Time Capsule icon should appear in your menu bar (top-right)
3. Click the icon to open the app

### Step 19: Run Tests

```bash
# Via Xcode
Product → Test (⌘U)

# Via command line
make test
```

### Step 20: Verify Setup

Run all verification commands:

```bash
# Build from command line
make build

# Run tests
make test

# Run linting
make lint

# Run security audit
make lint-security
```

## Troubleshooting

### Common Issues

#### Issue: "Cannot find 'TimeCapsuleApp' in scope"

**Cause**: Files not added to target

**Solution**:
1. Select the missing file
2. Open **File Inspector** (⌥⌘1)
3. Under **Target Membership**, check ☑ TimeCapsule

#### Issue: "No such module 'SwiftData'"

**Cause**: Deployment target too low

**Solution**:
1. Set minimum deployment target to **macOS 14.0**
2. SwiftData requires macOS 14.0+

#### Issue: Build fails with "Command SwiftLint failed"

**Cause**: SwiftLint not installed or configuration error

**Solution**:
```bash
brew install swiftlint
make lint-fix  # Auto-fix issues
```

#### Issue: App doesn't appear in menu bar

**Cause**: `LSUIElement` not set in Info.plist

**Solution**:
1. Open `Resources/Info.plist`
2. Add key `LSUIElement` (Boolean) = `YES`
3. Rebuild and run

#### Issue: "The operation couldn't be completed" when building

**Cause**: Code signing issues

**Solution**:
1. Go to **Signing & Capabilities**
2. Reselect your Team
3. Clean build folder (⇧⌘K)
4. Rebuild

#### Issue: Tests fail with "No such module 'TimeCapsule'"

**Cause**: Test target can't see main app code

**Solution**:
1. Add `@testable import TimeCapsule` at top of test files
2. Verify test target's **Build Settings → Enable Testability** = YES

#### Issue: SwiftLint reports many errors

**Cause**: Code doesn't match strict linting rules

**Solution**:
```bash
# Auto-fix what can be fixed
make lint-fix

# See what needs manual fixing
make lint
```

## Advanced Configuration

### Custom Bundle Identifier

If you want to use your own bundle identifier:

1. Update **General → Identity → Bundle Identifier**
2. Update in `Info.plist` if hardcoded
3. Update in **Signing & Capabilities** if using iCloud

### Code Signing for Distribution

For distributing the app:

1. Go to **Signing & Capabilities**
2. Change **Signing Certificate** to "Developer ID Application"
3. Enable **Hardened Runtime**
4. Archive and notarize:
   ```bash
   make archive
   ```

### Continuous Integration

The project includes GitHub Actions for CI/CD. See:
- `.github/workflows/ci.yml` - Build, test, lint
- `.github/workflows/codeql.yml` - Security analysis
